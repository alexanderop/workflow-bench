# reka-number-field-deletion

A NumberField formatted with a unit suffix such as 13 min traps Backspace at the suffix. Users must be able to delete through the suffix while editing. Deletion and history undo/redo input operations must remain usable even while the intermediate text is not a fully formatted number. Preserve validation of inserted text, composition input, numeric value updates, and reformatting on blur. Keep the public API unchanged.

Run the existing focused NumberField tests. Hidden acceptance tests will be applied after submission. Only production files in the declared scope may remain changed.
